## 2023-10-27 - Append-only table memory leak pattern\n**Learning:** When querying append-only tables (like `product_events` and `stock_snapshots`) to find the latest record, using PHP-side filtering like `->get()->unique(...)` loads excessive amounts of data into memory as the tables grow, leading to memory exhaustion.\n**Action:** Use SQL grouping subqueries with `MAX(id)` or `MAX(occurred_at)` combined with `whereIn` to fetch only the latest records directly from the database instead of loading everything and filtering in PHP.
